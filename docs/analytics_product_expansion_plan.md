# Sports Terminal Analytics Product Expansion

This phase turns the NBA analytics surface into a coherent workstation suite rather than a single statistics table.

## Flagship Stats Workstation

The existing workstation remains the core sortable table and already provides regular-season/playoff modes, positional filters, multiple rate bases, saved custom views, comparisons, charts, glossary, inline filters, favorites, density controls, exports and keyboard-first workflows.

## New connected analytics destinations

- Analytics Hub: launchpad and status board for the complete NBA research suite.
- Player Comparison Lab: side-by-side and indexed player comparison workflows.
- Team Analytics: team-level records, scoring, margins and factor views.
- Recent Form: rolling last-N-game player analysis from complete or sampled player game logs.
- Player Profiles: player summary, percentile and game-high views.
- Metric Catalog: definitions, families, formulas and data-availability boundaries.

## Product principles

- Preserve the Sports Terminal visual system and role shell.
- Prefer connected seed data over hard-coded showcase values.
- Make analytical objects routable to Workspace and Python Lab where practical.
- Clearly distinguish unavailable postseason or advanced-source data instead of fabricating it.
- Keep all customer surfaces usable with the current 2025–26 launch data architecture and validated development fallback.
